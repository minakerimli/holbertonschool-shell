# Holberton Shell

This repository contains Bash scripts for the Holberton School Shell project. All scripts are designed to be **simple, executable, and tested on Ubuntu 22.04 LTS**.  

## Project Overview

- Each script is exactly **two lines long**.
- The **first line** of every script is `#!/bin/bash`.
- All scripts **end with a newline**.
- No usage of backticks, `&&`, `||`, or `;` is allowed.
- A README.md is present at both the root and in each folder describing the scripts.
